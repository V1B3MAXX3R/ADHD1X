# ADHD1X project memory

Short notes that every AI helper (Claude, Gemini, Codex, others) reads at the start of a task, so Christian does not have to repeat himself. This folder is part of the repo, so every helper sees the same notes.

## How to use it
1. **Read this index first**, then open any note that looks relevant to your task.
2. **Notes can be out of date.** If a note names a file, command or setting, check it still exists before relying on it. If it is wrong, fix the note.
3. **Add a note** when Christian states a preference, corrects you, or confirms an approach that worked. One fact per file, short, with a **Why** and a **How to apply** line.
4. **Update, don't duplicate.** If a note already covers it, edit that note. Delete notes that turn out to be wrong.
5. **Never store** secrets or keys, passwords, the access code, real student data, grades, health or diagnosis details (A11, A15, A36), or anything already in the code, the git history or the decision log.
6. **The decision log wins.** `instructions/decision-log.md` holds the approved decisions (A1 and up). These notes are working habits and project facts, not decisions. If a note disagrees with the decision log, follow the log and tell Christian.
7. Add a one-line entry below for every note, and add a line to `coding/CHANGELOG.md` if the note changes how the code is built.
