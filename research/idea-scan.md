# Idea Scan: Similar Apps (2026-10-10)

**Version 1.1.1** (2026-10-10)

Status: all approved by Christian 2026-10-10 (A86 to A94; were T43 to T51) in [decision-log.md](../instructions/decision-log.md). Christian's framing: ADHD1X isn't competing with anyone, so this is a quick look for ideas worth borrowing, not a competitor audit (replaces Q8).

Filter: an idea only makes it here if it helps a student start, plan or finish schoolwork and doesn't break the rules (no guilt or streaks A5/A25, presets only A26, consent A4, diagnosis-free A11).

## Apps looked at

| App | What it's known for | Source |
|---|---|---|
| Tiimo | Visual color-coded day schedule, AI co-planner, focus timer, calendar sync, widgets | App Store listing |
| Goblin Tools | Magic ToDo (breakdown with a "spiciness" detail slider), Formalizer (rewrites tone), Judge (how a message might land), Compiler (brain dump to task list), one-task Taskmaster view | saner.ai review |
| Llama Life | One task at a time, a timebox per task, total time and estimated finish time, a "Not now" list, planned vs actual time reports, saved routines | App Store listing |
| Shovel | Student planner: time estimate per assignment, reading time from page count that adapts to your speed, "do you have enough time before this deadline?" check | Educational App Store listing |
| Focusmate | Virtual coworking: say your goal at the start of a session, check in on progress at the end | focusmate.com/how-it-works |

## Ideas worth borrowing

| # | Idea | Borrowed from | How it would work in ADHD1X | Fits |
|---|---|---|---|---|
| T43 | **Enough time? check** | Shovel | Before you accept a plan, plain logic checks whether your study blocks before each due date can fit the estimated work. If not, one calm line: "This essay needs about 3 more hours than your blocks have before Friday. Add a block?" No red warnings | A32, A41, A4 |
| T44 | **Finish-time estimate** | Llama Life | Today's plan shows "Done around 3:40 pm" based on task estimates, updating as you go | A32, A41 |
| T45 | **Not now list** | Llama Life | Swipe a task off today's plan without deleting it; it waits in a Not now list and the planner can pull it back later | A4, A25 |
| T46 | **Reading time from page count** | Shovel | For reading assignments, enter pages; the app estimates time and adjusts to your real pace over time. Plain logic, no Gemini | A40, A32 |
| T47 | **Private time check-back** | Llama Life | After a timer ends, optionally log how long a task really took. Used only to improve future estimates (planning fallacy), never shown as a score or compared | A41, A5 |
| T48 | **Session goal line** | Focusmate | When starting a timer, an optional one-line "what I'll do this session." At the end: "Done, partly, or not yet?" No tracking, no judgment | Help me start (A82) |
| T49 | **Tone buttons on professor emails** | Goblin Tools Formalizer / Judge | On "Message my professor" drafts: "More formal" and "Friendlier" buttons | A61, A26 |
| T50 | **Saved routines** | Llama Life | Save a reusable step list, like "Lab report routine," and drop it onto any similar assignment | A83 (reused first moves) |
| T51 | **Fix a conflict: brain dumps and Gemini** | Goblin Tools Compiler | A26 names "Sort my brain dump" as a preset, but the Help me start rules say brain dumps never go to Gemini. Proposed fix: Sort my brain dump is allowed only when the user taps it, with a one-line reminder not to include personal details (free tier, A15). Otherwise brain dumps stay local | A26, A15, A4 |

## Looked at and skipped

| Idea | Why skipped |
|---|---|
| Calendar sync (Tiimo, Shovel) and LMS import (Shovel) | Same reasons as Canvas (F3): setup, permissions, more personal data. Could join F3 later |
| Community hub, family sharing (Tiimo) | Personal project (A9); peer rooms already parked as F1 |
| Confetti on every task (Llama Life) | Already covered by optional celebrations (A24, quiz question 15) |
| Soundscapes (Llama Life) | Nice to have, but not school-specific; could be a later appeal feature (A23) |
| Home-screen widgets (Tiimo) | ADHD1X is a website for now; revisit if it becomes an installable app |
| Productivity insights and reports (Tiimo, Shovel) | Risks becoming a performance score, which conflicts with no-guilt rules (A5); T47 keeps only the useful part |
